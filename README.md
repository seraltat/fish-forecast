# Прогноз клёва 🎣

> **Автор:** Резниченко Сергей Иванович · ✉️ rezseriv@gmail.com  
> © 2026 Резниченко С. И. Все права защищены.

Персональное приложение для прогноза клёва рыбы на Дальнем Востоке России. Создано рыбаком для рыбака — учитывает реальные данные о погоде, температуре воды, фазе луны и сезонных особенностях каждого вида рыбы.

## Возможности

### Прогноз клёва
- **4 вида рыб в почасовом прогнозе**: карась, сазан, сом, щука
- **Почасовой прогноз** на 7 дней вперёд
- **Оценка от 0 до 100** с меткой: «Клёва нет» / «Слабый» / «Средний» / «Хороший» / «Отличный»
- Разбивка по факторам: температура воды, давление (тренд и значение), ветер (скорость и направление), время суток, фаза луны, облачность
- **Краснопёрка** не считается в per-spot прогнозе — у неё отдельный раздел (см. ниже)

### Краснопёрка — отдельный прогноз хода
Краснопёрка — полупроходная рыба, её ход в реки зависит от температуры воды в заливах, а не от конкретного места ловли. Поэтому прогноз краснопёрки вынесен в отдельный раздел:

- На вкладке **«Прогноз»** — красная иконка рыбы в правом верхнем углу
- По клику открывается диалог с:
  - **SST по каждому заливy отдельно** (Амурский залив — координаты 43.244764, 131.849619; Уссурийский залив — 43.239640, 132.277731)
  - **Статус миграции** по каждому заливy (по реальным наблюдениям):
    - SST > 16°C → «Рано» (краснопёрка ещё в море)
    - SST 11–16°C → «Начинается заход» (можно ловить в устьях и протоках)
    - SST 7–11°C → «Активный ход!» (массовый заход в реки — лучшее время)
    - SST 4–7°C → «Скаты на ямы» (заход на зимовальные ямы)
    - SST < 4°C → «На зимовальных ямах»
  - **Устья рек в заливах**: Амурский — Раздольная (Суйфун), Уссурийский — Артемовка (Майхе)
- Описание краснопёрки меняется по сезону: весна — весенний жор, осень — миграция, зима — глухозимье, лето — взрослая в море
- В Дневнике краснопёрка доступна для записи улова как обычный вид рыбы

### Сезонная логика
Для каждого вида рыбы — свои правила (по реальным наблюдениям рыболовов):
- **Зима (дек-фев)**: «Глухозимье» только при воде < 4°C; при 4-10°C — «Зимняя пассивность» (клюёт в оттепель)
- **По первому льду (декабрь)**: карась ещё активен на глубине до 3 м
- **Весна (мар-май)**: «Весенний жор!» — карась жадно питается на мелководье, неприхотлив к насадкам
- **Нерест (май-июль)**: вода 15-20°C — клёв прекращён
- **Посленерестовый жор (май-июль)**: вода 20-25°C — пик активности!
- **Лето (июн-авг)**: «Жара — кислород падает» для карася при воде > 25°C
- **Осень (сен-ноя)**: «Осенний жор» при воде 8-12°C — карась активно кормится, накапливая жир; «Сезон заканчивается» при 4-8°C — на глубинных ямах, но клюёт
- **Щука** активна круглый год (холодноводный хищник)

### Температура воды
- **Оценка по воздуху** — для всех мест: средняя температура воздуха за прошлые 3 дня → оценка температуры воды (отдельно для реки и озера)
- **Ручной ввод** — на «Корректировке» введите измеренную термометром температуру
- Приоритет: ручной ввод > оценка по воздуху
- SST (температура моря в заливах) используется **только** для краснопёрки — в отдельном разделе

### Корректировка на месте
- Приехали на место — откройте вкладку «Корректировка»
- Введите измеренную температуру воды, фактический ветер и давление
- Прогноз **пересчитается автоматически** с учётом ваших данных

### Лунный календарь
- Фаза луны по данным Open-Meteo (точное значение)
- Восход/заход луны для координат места
- 28-дневная таблица оценки клёва по лунным дням
- Лунный день отображается на «Главной»

### Дневник улова
- Запись каждой пойманной рыбы: вид, вес, длина, наживка, фото
- **5 видов рыб** доступны в дневнике: карась, сазан, сом, щука, краснопёрка
- **Быстрый ввод нескольких рыб** одним кликом (количество + средний вес)
- **Разнорыбица** (Монгольский краснопёр, Остробрюшка, Касатка, Конёк) — только для места «Канал»
- **Фото улова** — камера телефона, авто-сжатие, хранение в базе
- **Определить рыбу** — AI-распознавание вида по фото (нужен интернет)
- **Поделиться** — отправить сводку за день в Telegram, WhatsApp и т.д.
- Сводка за день: «Карась ×3 (0.6 кг), Щука ×2 (1.4 кг) — Итого: 5 рыб, 2.0 кг»

### Аналитика
- **Фильтр по месту** — выберите конкретный спот или «Все места»
- График улова по видам рыб (краснопёрка отображается там, где есть её уловы)
- Точность прогноза (hit-rate): «Когда прогноз был >60%, вы действительно ловили в N% случаев»
- Распределение улова по корзам прогноза (0-20, 20-40, 40-60, 60-80, 80-100)
- **Рекомендации** по корректировке весов алгоритма на основе ваших данных
- Кнопка «Применить» с подтверждением (необратимо — только с реальными данными!)
- Кнопка «Сбросить к стандартным весам» — откат к исследованным значениям

### Карта
- Просмотр места на карте (Leaflet + OpenStreetMap)
- Выбор места на карте при добавлении (с поиском по названию через Nominatim)
- Доступно для каждого места в Настройках

### Места лова
- 7 пресетов дальневосточных рек: Уссури, Бикин, Раздольная, Артемовка, Кипарисовка, Илистая, Канал
- Или введите свои координаты вручную
- Или выберите на карте
- **Тип воды**: Озеро / Река / Протока / Канал
- **Описание** (необязательно) — показывается в скобках рядом с названием места на Главной
- Кнопка **«Изменить»** в Настройках — правильно заполняет форму данными выбранного места (название, координаты, тип, описание)

### Изоляция данных
- Каждый браузер/телефон имеет свои данные (анонимный ID)
- Друзья, открывшие ссылку, видят **пустую базу** — ваших данных нет
- Конфиги рыб (веса алгоритма) — общие для всех

### Экспорт / Импорт
- **Экспорт данных в JSON** — резервная копия мест, уловов, настроек
- **Импорт из JSON** — восстановление на новом устройстве или сервере

## Как установить на телефон (Android)

1. Откройте ссылку приложения в **Google Chrome**
2. Нажмите ⋮ (три точки) → **«Установить приложение»**
3. Иконка «Клёв» появится на главном экране
4. Приложение открывается fullscreen, без адресной строки

## Как пользоваться

### Перед рыбалкой (дома)
1. Откройте вкладку **«Прогноз»** — увидите оценки на 7 дней
2. Выберите целевую рыбу на «Главной» (тап по чипу рыбы)
3. Посмотрите **лучший час** клёва на карточке дня
4. Нажмите **«Почему?»** — увидите разбивку по факторам
5. Для краснопёрки — нажмите **красную иконку рыбы** в правом верхнем углу вкладки «Прогноз»

### На месте рыбалки
1. Откройте вкладку **«Корректировка»**
2. Введите измеренную **температуру воды** (термометром)
3. При необходимости — фактический ветер и давление
4. Прогноз пересчитается автоматически
5. Нажмите **«Начать сессию»** — уловы привяжутся к этой рыбалке

### После рыбалки
1. Откройте вкладку **«Дневник»**
2. Нажмите **«Добавить улов»**
3. Выберите вид рыбы (или «Разнорыбица» для Канала)
4. Введите вес и длину
5. Прикрепите фото (опционально)
6. Можно ввести несколько рыб сразу (вкладка «Несколько рыб»)
7. Нажмите **«Поделиться»** — отправьте сводку друзьям

### Периодически
1. Откройте **«Аналитика»** — проверьте точность прогноза
2. Если прогноз систематически ошибается — нажмите «Применить» на рекомендации
3. Используйте **«Сбросить к стандартным весам»** если что-то пошло не так

## Технологии

- **Next.js 16** + TypeScript + Tailwind CSS 4 + shadcn/ui
- **Prisma ORM** + PostgreSQL (Supabase) / SQLite (локально на Raspberry Pi)
- **Open-Meteo API** — погода, фаза луны
- **Open-Meteo Marine API** — SST (температура моря в заливах) для краснопёрки
- **Leaflet + OpenStreetMap** — карта
- **z-ai-web-dev-sdk** — AI-распознавание рыбы по фото
- **PWA** (Progressive Web App) — устанавливается на телефон, работает офлайн (кешированный UI)

## Размещение

Приложение развёрнуто в нескольких вариантах:

### Вариант 1: Vercel + Supabase (публичный, для друзей)
- Frontend на Vercel (бесплатный хостинг)
- База данных на Supabase (бесплатный PostgreSQL)
- Постоянный URL — можно делиться с друзьями
- Может нестабильно работать при rate-limit от Open-Meteo (429)

### Вариант 2: Raspberry Pi (личный сервер, без лимитов)
- Standalone production-бандл запускается через `node .next/standalone/server.js`
- База данных — локальная SQLite (`prisma/dev.db`)
- **Node.js 18 LTS ARM64** — единственный стабильно работающий runtime на Pi 4
  (Node 20 и Bun падают с `Illegal instruction` из-за несовместимости V8 с Cortex-A72)
- Доступ из домашней сети: `http://<IP-малинки>:3000`
- **Доступ из любой сети** (с телефона на рыбалке) — через **Cloudflare Tunnel**:
  ```bash
  cloudflared tunnel --url http://localhost:3000
  ```
  Создаёт публичный HTTPS-URL вида `https://random-words.trycloudflare.com`
- Преимущества: без Vercel таймаутов, без 429 от Open-Meteo (вы единственный пользователь), старт за 300мс

## Алгоритм прогноза

Оценка клёва = взвешенная сумма факторов, умноженная на **температурный множитель** (квадратичный — если вода холодная, оценка подавляется):

```
Итог = (Σ вес_фактора × subscore_фактора) × tempGate × seasonModifier
```

Где:
- **tempGate** = (waterTempSubscore / 80)² — если < 80, штраф квадратичный
- **seasonModifier** = ×0.15 (не сезон / нерест) / ×1.10 (посленерестовый жор) / ×0.85 (осеннее охлаждение) / ×1.0 (активно)

Факторы и веса настроены на основе исследований рыболовного сообщества и могут корректироваться через «Аналитика → Применить».

### Алгоритм краснопёрки

Краснопёрка — особый случай:

- **Не считается в per-spot прогнозе** — её ход зависит от SST в заливах, не от конкретной реки
- **Сезон определяется по SST** в заливах (глобально, не по месту):
  - SST > 16°C → «Рано» (ещё в море)
  - SST 11–16°C → «Начинается заход» (можно ловить в устьях и протоках)
  - SST 7–11°C → «Активный ход!» (массовый заход в реки)
  - SST 4–7°C → «Скаты на ямы» (заход на зимовальные ямы)
  - SST < 4°C → «На зимовальных ямах»
- Прогноз по краснопёрке доступен отдельной красной иконкой рыбы во вкладке «Прогноз»

### Рекомендации по лову (диалог «Почему?»)

При тапе на час в прогнозе открывается диалог «Почему такая оценка?», где помимо разбивки по факторам есть блок **«Рекомендации по лову»** (пока только для карася, на основе рыбацких статей):

- **Глубина** — где искать (мелководье / бровки / ямы с твёрдым дном и т.д.)
- **Насадка** — животные (мотыль, червь, опарыш) или растительные (перловка, кукуруза, ароматизаторы)
- **Время** — лучшее время суток (10-17, 4-8 утра, 12-16 и т.д.)
- **Снасти** — поплавочная / фидер / матчевая / зимняя удочка
- **Нюанс** — дополнительные советы (например, «избегать мелководья <1.5 м», «стаи и глубина», «вегетарианец летом»)

Рекомендации динамические — меняются по сезону и температуре воды.
